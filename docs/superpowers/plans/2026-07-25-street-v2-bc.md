# Street v2 B/C Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the installed Street v2 art into a living neighbourhood — a wide time-of-day backdrop, landmarks that rise through construction stages as the player levels, and three named neighbours who move in when their building finishes.

**Architecture:** Three new pure modules (`street-backdrop`, `street-construction`, `street-neighbours`) hold all logic and derive from the player's level or a time-of-day value; `src/ui/street-screen.js` renders them. Only one new stored field (`metNeighbours`, a grant-once guard) — construction stage and neighbour presence derive from level and are never stored. `main.js` stays frozen.

**Tech Stack:** Vanilla JS ES modules, Vitest, esbuild. Canvas 2D rendering. No new dependencies.

## Global Constraints

- **`main.js` is frozen** — no new feature wiring there; extend `src/ui/street-screen.js` only.
- **Never touch learning state** — no writes to quests/daily/growth/mastery/srs/boss; keepsake `word` is a read-only snapshot string.
- **Persistence via `src/storage.js`**; the only new stored field is `metNeighbours` inside the synced `nbhsk.shop.streetLayout`.
- **Any stored-shape change needs a migration** — bump `CURRENT_SCHEMA_VERSION` and append one guarded `{ to, up }` ladder entry; never throw on corrupt data.
- **file:// resilience** — the scene must render with no wide-webp art present (fall back to the painted base / existing `bg-street`).
- **Full `npm test` unmasked + `npm run lint` + `npm run build`** gate every commit. Never pipe test output to tail/grep when gating.
- **No PRECACHE / SHELL change in these tasks** — the wide backdrops are runtime-cached; the release cut that later ships this bumps SHELL as usual.
- **New player-facing strings** are `t("street.*")` keys with parallel EN + TH in `src/i18n.js`; TH tagged for native spot-check.
- **Palette / art** already approved in `assets/asset-manifest.json`; do not regenerate art.

```javascript
"use strict";
// Pure time-of-day → wide-backdrop selection. No clock, no storage: the caller
```

```javascript
// src/street-construction.js
"use strict";
// Pure landmark construction-stage model. A landmark's visible stage is a
// function of the player's level between the previous milestone and its own
// unlock level — nothing here reads storage. Reuses projectStage's 0/1/2/3
// bucket so construction shares the same thresholds as coin projects.
import { BUILDINGS } from "./street.js";
import { projectStage } from "./street-project.js";

function span(id) {
  const idx = BUILDINGS.findIndex(b => b.id === id);
  if (idx < 0) return null;
  const thisUnlock = BUILDINGS[idx].lv;
  const prevUnlock = idx > 0 ? BUILDINGS[idx - 1].lv : 0;
  return { thisUnlock, prevUnlock };
}

export function landmarkStage(level, id) {
  const s = span(id);
  if (!s) return 0;
  const lv = Number(level) || 0;
  if (lv >= s.thisUnlock) return 3;
  return projectStage(lv - s.prevUnlock, s.thisUnlock - s.prevUnlock);
}

export function constructionSprite(id, stage) {
  if (stage <= 0) return null;
  if (stage >= 3) return `landmark-${id}`;
  return `landmark-${id}-stage${stage}`;
}
```

```javascript
// src/street-neighbours.js
"use strict";
// Pure model for the three named neighbours who live on the Street once their
// landmark is finished. Presence derives from level; nothing here reads storage
// or the clock. Anchors are hand-placed x-fractions beside each building
// (coin-bank .34, tailor .5, kitten-cafe .66 slots → stand just to the side).

export const NEIGHBOURS = [
  { id: "tiao", landmarkId: "coin-bank",  unlock: 10, anchor: 0.40 },
  { id: "pang", landmarkId: "tailor",     unlock: 20, anchor: 0.56 },
  { id: "wen",  landmarkId: "kitten-cafe", unlock: 30, anchor: 0.72 },
];

export function residentNeighbours(level) {
  const lv = Number(level) || 0;
  return NEIGHBOURS.filter(n => lv >= n.unlock).map(n => n.id);
}

export function newlyMovedIn(level, met) {
  const seen = new Set(Array.isArray(met) ? met : []);
  return residentNeighbours(level).filter(id => !seen.has(id));
}

const REST_MS = 16000;      // idle at the anchor
const WALK_MS = 4000;       // short stroll out
const RETURN_MS = 4000;     // and back
const CYCLE_MS = REST_MS + WALK_MS + RETURN_MS;
const STROLL = 0.06;        // how far (x-fraction) the neighbour wanders

function smoothstep(t) { return t * t * (3 - 2 * t); }

export function neighbourPose(nowMs, anchor, reducedMotion) {
  const a = Number(anchor) || 0;
  if (reducedMotion) return { x: a, facing: 1, sprite: "idle" };
  const now = ((Number(nowMs) || 0) % CYCLE_MS + CYCLE_MS) % CYCLE_MS;
  const walkSprite = Math.floor((Number(nowMs) || 0) / 200) % 2 === 0 ? "walk-a" : "walk-b";
  if (now < REST_MS) return { x: a, facing: 1, sprite: "idle" };
  if (now < REST_MS + WALK_MS) {
    const t = smoothstep((now - REST_MS) / WALK_MS);
    return { x: a + STROLL * t, facing: 1, sprite: walkSprite };
  }
  const t = smoothstep((now - REST_MS - WALK_MS) / RETURN_MS);
  return { x: a + STROLL * (1 - t), facing: -1, sprite: walkSprite };
}
```
